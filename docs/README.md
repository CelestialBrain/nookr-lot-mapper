## Key Features

- **Offline-First**: Works without internet after initial load
- **PWA Support**: Install as app on any device
- **Tile Caching**: Download map tiles for field use
- **IndexedDB Storage**: All data stored locally
- **Share Codes**: Transfer data between devices
- **Multi-Project**: Manage multiple subdivisions
- **Areas/Grouping**: Organize lots into named groups
