# Getting Started

## Prerequisites

- Node.js 18+
- npm or yarn

## Installation

```bash
# Clone the repository
git clone <repository-url>
cd nookr-lot-mapper

# Install dependencies
npm install

# Start development server
npm run dev
```

The app will open at `http://localhost:5173`

## Mobile Access

To access on your phone:

1. Find your computer's local IP (e.g., `192.168.1.100`)
2. Run `npm run dev -- --host`
3. Open `http://192.168.1.100:5173` on your phone

## First Steps

1. **Allow GPS** - Tap the 📍 button to enable location tracking
2. **Create a Lot** - Use the Draw tool or Edge Detect
3. **Save Details** - Tap a lot to add owner info and notes

## Keyboard Shortcuts

| Shortcut | Action |
|----------|--------|
| `S` | Select tool |
| `D` | Draw tool |
| `E` | Edit tool |
| `X` | Delete tool |
| `Ctrl+Z` | Undo |
| `Ctrl+Shift+Z` | Redo |
| `Escape` | Cancel/Deselect |
