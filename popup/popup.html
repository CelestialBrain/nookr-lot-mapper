Quick Start

  1. Open Google Maps in satellite view
  2. Navigate to your subdivision
  3. Click a tool from the overlay toolbar
  4. Draw or auto-detect lot boundaries
  5. Export data for your HOA app

Keyboard Shortcuts

S Select
D Draw
A AI Select
E Edit
X Delete
Esc Deactivate

Tips

  • 🪄 AI Select works best on contrasting rooftops
  • ✏️ Double-click to complete a polygon
  • 🔧 Drag vertices in Edit mode to adjust
  • 💾 Data saves automatically to browser storage
